# Analog_controller
Comprehensive guide for building and assembling the electronics for a Coherent Analog Controller, specifically for a oherent Compass-M Green DPSS Laser. This builds off the work of Samuel M. Goldwasser.

## Repository structure
- `3d-designs-and-builds/` - 3D design files and general build designs
- `schematics-and-electronic-designs/` - schematics and electronic design files
- `code/` - source code and related software files
